## 3.0.1

## 3.0.0

Requires macOS 15 or later, including macOS 27 Golden Gate. After upgrading from 2.x, add your servers again with their addresses and API tokens.

- Show cluster CPU or the running guest count in the menu bar.
- Add small or medium widgets for individual servers.
- Receive guest and node status notifications across all configured servers.
- See connection failures in the dashboard when cluster data cannot be refreshed.
